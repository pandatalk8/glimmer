# 产品需求文档

微光翻译 Glimmer 是一款 Chrome 沉浸式双语翻译扩展：打开任意英文网页，译文按段落插在原文下方，读起来像一本双语书。Google 翻译免费开箱即用；想要 DeepL 的地道译文、AI 大模型的精翻和多设备同步的生词本，开通会员。

本文回答“产品要做什么、做到什么程度算完成”。每条需求都标了状态和对应的测试用例编号，改动需求时同步修改这里、[交互设计](ux-design.md) 和 [测试用例](test-cases.md)。

## 一、产品定位

**一句话：** 打开网页就能翻译，免费；想要更好的译文和云端生词本，开通会员。

| 用户 | 典型场景 | 最在意什么 |
| --- | --- | --- |
| 读英文资料的学生、研究者 | 读论文、技术文档、维基百科 | 原文译文对照、不破坏排版、术语准确 |
| 工程师 | 读 GitHub、Hacker News、英文博客 | 一键翻译、代码块不被翻译、速度快 |
| 学英语的人 | 看 YouTube、读新闻、积累生词 | 双语字幕、划词查词、生词本 |
| 重度用户 | 每天大量阅读，要求译文质量 | DeepL / 大模型、多设备同步 |

**产品原则**（详见 [交互设计](ux-design.md) 第二节）：

1. **永不阻断阅读。** 付费引擎不可用时自动改用 Google，提示一次原因。
2. **先说明，再跳转。** 点到会员功能时原地弹出提示卡，用户点“查看会员方案”才离开当前页面。
3. **从哪来，回哪去。** 付款、登录、管理订阅结束后回到发起的页面，并告诉用户结果。
4. **付完钱马上能用。** 开通成功后一步把默认引擎换成刚解锁的引擎。
5. **会员状态只信服务端。** 客户端只读取与缓存，从不决定谁是会员。

## 二、会员方案

价格以美元计，Stripe 收款。

| 方案 | 价格 | 翻译引擎 | 生词本 | 其他 |
| --- | --- | --- | --- | --- |
| 免费版 | $0 | Google | 本机，最多 100 个 | 全部翻译方式、YouTube 双语字幕；不需要登录 |
| Premium | $29 / 年（仅年付） | + DeepL、Microsoft | 不限数量（上限 5000），云同步 | 需要登录 |
| Premium+ | $6 / 月，或 $69 / 年 | + GPT、Gemini、DeepSeek、Claude | 同 Premium | 每月 2000 万 Token，每月 1 日（UTC）重置 |

**规则：**

- 付费引擎全部由后端翻译代理调用，服务商 Key 只在服务器；扩展里不能、也不需要填写任何 API Key
- 同一用户只保留一个订阅：已是会员时升级、换方案都在 Stripe 客户门户中完成，差价按剩余天数折算
- 取消续费后权益保留到当前周期结束；扣款失败（`past_due`）期间保留权益并提示更新支付方式
- Premium+ 额度用完后，大模型暂停到下月 1 日，DeepL、Microsoft、Google 照常可用

## 四、非功能需求

| 类别 | 要求 | 实现 |
| --- | --- | --- |
| 性能 | 首屏快速出结果；请求少 | 视口懒加载、80ms 合并、批量接口、IndexedDB 缓存；Hacker News 首页 65 段约 1 秒、2 个请求 |
| 兼容 | React、Vue 页面开关翻译不出错 | 只插入自己的元素，仅译文用样式隐藏原文 |
| 隔离 | 扩展界面不受网页样式影响，网页读不到登录令牌 | 小组件用 Shadow DOM，侧边面板用扩展页 iframe |
| 安全 | 扩展中没有服务商 Key 和服务端密钥 | Key 只在 Supabase secrets；扩展只有可公开的 publishable key（H-06） |
| 隐私 | 翻译内容不保存 | Google 由浏览器直连；会员引擎经后端只转发，只记字数和 Token 数 |
| 可靠 | 支付通知重复或乱序不出错 | 事件去重，以订阅当前状态为准；失败返回 500 让 Stripe 重试 |
| 防滥用 | 翻译代理不能被白嫖 | 必须登录，按等级校验引擎，Premium+ 月度 Token 上限，单次最多 100 段 / 2 万字符 |
| 超时 | 不出现一直转圈的段落 | Google 20 秒、翻译代理 90 秒超时，给出中文错误 |

架构上的理由和取舍见 [架构设计说明](architecture.md)。

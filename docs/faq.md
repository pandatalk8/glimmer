# 常见问题

---

## 一、安装与使用

**点击“翻译此页面”是灰色的，提示“当前页面不支持翻译”？**

两种情况：一是浏览器内置页面（`chrome://`、Chrome 应用商店、新标签页），Chrome 禁止扩展在这些页面运行；二是安装或更新扩展之前就已经打开的网页，刷新一下即可。

**本地 HTML 文件（`file://`）无法翻译？**

在 `chrome://extensions` 中打开本扩展的“详细信息”，开启“允许访问文件网址”。

**悬浮球挡住了网页按钮？**

上下拖动悬浮球调整位置（位置在当前标签页内保持）。也可以在悬浮球的菜单中点“隐藏”只在本页隐藏，或在面板 → 设置 → 浮动按钮中彻底关闭。

**侧边面板挡住了网页内容？**

再次点击工具栏图标、点击面板右上角的 ✕，或按 `Esc` 收起。

**为什么在某些页面点击图标是弹窗，而不是侧面板？**

`chrome://` 开头的浏览器设置页、Chrome 应用商店等页面禁止扩展嵌入内容，这些页面上会自动改用弹窗显示面板，功能相同，只是无法翻译当前页面。面板打开时悬浮球会移到面板左侧，仍可用来开关翻译。

**生词本保存在哪里？换电脑会同步吗？**

保存在本机浏览器的扩展存储中，不会同步到其他设备，也不包含在“导出设置”的文件里。卸载扩展会清空生词本。

**翻译了一半，往下滚动才继续？**

这是设计如此。为了节省额度，只有进入视口（以及上下 600px 范围内）的段落才会翻译。

**有些段落没有被翻译？**

扩展会跳过这些内容：代码块、输入框、按钮、标记了 `translate="no"` 或 `notranslate` 的元素，以及已经是目标语言的文本。如果某段确实需要翻译，按住 `Alt` 把鼠标悬停在该段落上即可单独翻译。

## 二、翻译引擎

**还能在设置里填自己的 API Key 吗？**

不能了。Google 翻译免费可用；DeepL、Microsoft 需要 Premium，GPT、Gemini、DeepSeek、Claude 需要 Premium+，由我们的后端统一调用，你不用去各家申请 Key。旧版本中填写的 Key 和“自定义”引擎在更新后会被清除。

**选择 DeepL 或大模型时打开了会员方案页？**

该引擎需要更高的会员等级。引擎列表中每个引擎都标注了所需等级（免费 / Premium / Premium+）。

**提示“需要登录并开通会员后使用”？**

会员引擎需要先登录。面板 → 设置 → 账户登录后再试；已登录仍提示时，在账户页点击刷新按钮更新会员状态。

**提示“本月 AI 翻译额度已用完”？**

Premium+ 每月可用 2000 万 Token，账户页可以看到本月用量。额度在每月 1 日（UTC）恢复；期间 DeepL、Microsoft 和 Google 翻译仍可使用。

**显示“错误 429”？**

请求太频繁。Google 免费接口偶尔会被限流，等几分钟或切换到会员引擎。

**提示“服务端尚未配置 … 的 API Key”？**

后端还没有为这个引擎配置服务商 Key（自建后端时常见），换用其他引擎，或按 [后端部署指南](backend.md) 第四部分设置。

**大模型翻译很慢？**

整页翻译时，大模型每批最多翻译 16 段，比机器翻译慢是正常的。可以：选择更快的模型（如 `gpt-4.1-mini`、`gemini-2.5-flash`、`claude-haiku-5-5`、`deepseek-chat`）；避免推理模型（`deepseek-reasoner`、`gpt-5` 系列会先思考）；日常浏览用 Google，精读文章时再切换到大模型。

**大模型的译文偶尔夹带“以下是翻译”之类的话？**

在“AI 翻译设置”中检查提示词是否包含“Output only the translation”。也可以把 Temperature 调到 0。

**切换引擎后，页面上的旧译文会更新吗？**

会。修改引擎、目标语言或源语言后，正在翻译的页面会自动清除旧译文并用新设置重新翻译。

**缓存会导致改了提示词后译文不变吗？**

会。缓存按“引擎 + 模型 + 语言 + 原文”区分，不包含提示词。修改提示词后请到设置页“高级”中清除缓存。

## 三、YouTube 字幕

**打开了视频，但没有双语字幕？**

需要在播放器中点击 CC 按钮打开字幕。扩展通过拦截播放器自己的字幕请求获取字幕，所以视频必须有字幕（人工字幕或自动生成字幕均可）。如果仍然没有，刷新页面后重新打开 CC。

**字幕翻译到一半停了？**

字幕按每 40 句一批翻译，优先翻译当前播放位置附近的内容。若中途失败，页面顶部会显示错误提示，通常是引擎限流或额度问题。

**全屏时点击单词没有弹出释义？**

已知限制：翻译面板挂在页面根节点上，全屏时不可见。退出全屏后点击单词即可。

## 四、隐私

**扩展里有 API Key 吗？**

没有。服务商的 Key 只保存在我们的服务器上。扩展只保存你的登录令牌，存放在扩展存储中，网页脚本无法读取。

**网页内容会被发送到哪里？**

使用 Google 翻译时，文本由浏览器直接发给 Google，不经过我们的服务器。使用会员引擎（DeepL、Microsoft、大模型）时，文本经我们的服务器转发给对应服务商，服务器只记录字数和 Token 数，不保存原文和译文。我们保存的数据只有邮箱、订阅状态、每月用量，以及会员的生词本。处理敏感页面（如邮箱、内部系统）时，可以把这些域名加入“永不翻译”。

## 五、账户与订阅

**不登录能用吗？**

能。Google 翻译、划词、字幕、生词本（最多 100 个）都不需要登录。账户用于开通会员：Premium（$29 / 年）解锁 DeepL、Microsoft、无限生词本和云同步；Premium+（$6 / 月或 $69 / 年）再加上 GPT、Gemini、DeepSeek、Claude，每月 2000 万 Token。

**从 Premium 怎么升级到 Premium+？**

面板首页右上角“Premium”打开方案页，点击“升级到 Premium+”，会打开 Stripe 客户门户，在那里切换方案，差价按剩余天数折算。这样不会产生两份订阅。

**生词本满 100 个了？**

免费版最多收藏 100 个生词，删除一些后可以继续收藏，或开通 Premium 不限数量。会员的生词本会自动同步到云端，换电脑后登录即可恢复。

**支付安全吗？我的银行卡信息会被保存吗？**

支付在 Stripe 的页面上完成，银行卡信息只由 Stripe 处理，扩展和我们的服务器都接触不到。

**支付成功了，但面板还显示免费版？**

通常几秒内会自动更新。如果超过一分钟，在账户页点击邮箱右侧的刷新按钮；仍未更新请联系我们并提供支付邮箱。

**怎么取消订阅？取消后还能用多久？**

账户页点击“管理订阅”，在 Stripe 页面中取消。取消后会员权益会一直保留到当前付费周期结束，不会立即失效，也不会再扣费。

**收不到验证邮件或重置密码邮件？**

先检查垃圾邮件文件夹。短时间内多次发送会被限流，请几分钟后再试。

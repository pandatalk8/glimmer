# 测试用例：用户全旅程与会员权限

本文给测试人员使用：按一个真实用户的完整旅程，从注册、登录、免费翻译，到开通会员、使用付费功能、管理订阅，逐条验证；并专门检查**免费用户用不了付费功能、每个等级只能用到自己的权益**。

每条用例都写明前置条件、操作步骤和预期结果。实际结果填在“结果”列：通过记 ✅，不通过记 ❌ 并在第十二节记录问题。

---

## 一、测试环境准备

### 1.1 需要运行的服务

在项目根目录（`~/workspace/translator`，`dev` 分支）依次启动，每条命令占一个终端：

```bash
npx supabase start                                      # 本地数据库、登录、邮件（需先打开 Docker Desktop）
npx supabase functions serve --env-file supabase/functions/.env   # 后端函数：翻译代理、支付
stripe listen --forward-to http://127.0.0.1:54321/functions/v1/stripe-webhook \
  --events checkout.session.completed,customer.subscription.created,customer.subscription.updated,customer.subscription.deleted
python3 scripts/seed_review_accounts.py                 # 预置测试账号（可重复执行，用于重置）
```

### 1.2 加载插件并切到本地后端

1. Chrome 打开 `chrome://extensions`，开启开发者模式，“加载已解压的扩展程序”选择项目根目录；已加载过则点刷新
2. 完整设置页 → 高级 → “当前版本”，提交编号与 `git log --oneline -1` 一致
3. 同一区域的“后端（开发版）”选择“本地（127.0.0.1:54321）”。切换会退出当前登录

> 也可以在云端测试（“后端”选“云端”）。区别：云端会发送真实验证邮件，但每小时只能发几封，且只发给 Supabase 项目成员的邮箱；本地的邮件全部进 Mailpit，不限数量。

### 1.3 查看后台数据的地方

| 工具 | 地址 | 用来看什么 |
| --- | --- | --- |
| Mailpit（本地邮箱） | http://127.0.0.1:54324 | 验证邮件、重置密码邮件 |
| Supabase Studio | http://127.0.0.1:54323 → Table Editor | `profiles`（会员等级）、`subscriptions`、`usage_monthly`（用量）、`words`（云端生词） |
| Stripe 沙盒后台 | https://dashboard.stripe.com （选“GLIMMER 沙盒”） | 客户、订阅、付款、支付通知发送记录 |
| 后端函数日志 | 运行 `functions serve` 的终端 | 翻译代理、支付通知的处理结果 |

### 1.5 当前已配置的服务商

后端目前配置了 **DeepL** 和 **DeepSeek** 的 Key。Microsoft、GPT、Gemini、Claude 还没有配置：等级校验通过后，会提示“服务端尚未配置 … 的 API Key”。这算权限检查**通过**（说明请求已越过会员校验），不算缺陷。

## 二、权限矩阵（核心）

测试的核心是下面这张表。“✓”表示可以使用，“✗”表示必须被拦下并给出升级提示。

| 功能 | 未登录 | 免费版 | Premium | Premium+ |
| --- | --- | --- | --- | --- |
| 整页 / 划词 / 悬停 / 输入框翻译（Google） | ✓ | ✓ | ✓ | ✓ |
| YouTube 双语字幕（Google） | ✓ | ✓ | ✓ | ✓ |
| 生词本 | ✓ 最多 100 个 | ✓ 最多 100 个 | ✓ 不限 | ✓ 不限 |
| 生词本云同步 | ✗ | ✗ | ✓ | ✓ |
| DeepL、Microsoft 翻译 | ✗ 需登录 | ✗ 需 Premium | ✓ | ✓ |
| GPT、Gemini、DeepSeek、Claude | ✗ 需登录 | ✗ 需 Premium+ | ✗ 需 Premium+ | ✓ 每月 2000 万 Token |
| 账户页“本月 AI 用量” | — | — | — | ✓ |

**两种拦截方式：** 用户**手动选择**未解锁的引擎时，原地说明需要什么会员；**默认引擎**用不了时（未登录、会员到期、额度用完），网页翻译**自动改用 Google**，网页上提示一次，绝不显示整页“翻译失败”。

被拦下时的提示文字：

| 情况 | 提示 |
| --- | --- |
| 未登录使用付费引擎 | “DeepL 需要登录并开通会员后使用” |
| 免费版使用 DeepL / Microsoft | “该翻译引擎需要 Premium 会员，请升级后使用” |
| 免费版或 Premium 使用大模型 | “该翻译引擎需要 Premium+ 会员，请升级后使用” |
| Premium+ 用量用完 | “本月 AI 翻译额度（20 百万 Token）已用完，下月 1 日恢复” |
| 免费版第 101 个生词 | “免费版生词本最多 100 个，升级 Premium 不限数量”，带“查看会员方案”按钮 |
| 面板中点未解锁的引擎 | 升级提示卡：“DeepL 需要 Premium 会员”、价格、权益、“查看会员方案”“以后再说” |
| 默认引擎不可用，已自动改用 Google | 网页提示“DeepL 需要 Premium 会员，已改用 Google 翻译”（未登录时为“需要登录并开通会员”；额度用完时为“本月 AI 翻译额度已用完，已改用 Google 翻译”）；面板首页横幅“DeepL 需要 Premium 会员，正在使用 Google 翻译” |

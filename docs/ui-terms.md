# 界面术语表

给产品提修改意见时，用这里的名称指代界面上的位置，双方就不会对错位置。比如“图标栏去掉字幕按钮”“翻译开关卡片挪到最上面”“划词面板底栏加一个分享按钮”。

每个名称后面附了对应的代码位置，方便开发时直接定位。

---

## 一、侧边面板

点击工具栏图标后，从网页右侧滑出的整个区域叫**面板**。在 `chrome://` 等浏览器内置页面上，它以弹窗形式出现，内容相同。

```
┌──────────────────────────────────┬──────┐
│ 标题栏：Logo · 微光翻译 · Premium 入口│ 关闭 │
├──────────────────────────────────┤ ──── │
│ ┌ 生词本卡片 ┐  ┌ 翻译引擎卡片 ┐     │ 首页 │
│ └───────────┘  └─────────────┘     │ 设置 │
│ ┌ 翻译开关卡片：翻译此页面   ◯ ┐      │ 翻译 │
│ └────────────────────────────┘      │ 划词 │
│ ┌ 网站卡片：总在此网站开启   ◯ ┐      │ 字幕 │
│ │ 网址              永不翻译 · 0 ›│     │ 生词本│
│ └────────────────────────────┘      │      │
│ 本页生词区：本页生词 4    展开释义 ⌄  │      │
│   生词行：单词  ☑ ♥ 🔊               │      │
│ ┌ 快速翻译框 ┐                       │      │
│ └───────────┘                       │ 完整 │
│              ↑ 主区域                │ 设置 │
└──────────────────────────────────┴──────┘
                                       ↑ 图标栏
```

### 1.1 整体结构

| 名称 | 指的是 | 代码位置 |
| --- | --- | --- |
| **面板** | 整个侧边面板 | `panel/panel.html`；网页中的外层容器为 `ui.css` 的 `.drawer` |
| **主区域** | 图标栏左侧显示内容的部分 | `#main` |
| **标题栏** | 顶部 Logo、“微光翻译”、Premium 入口；进入子页面后显示返回箭头和页面标题 | `.hd` |
| **Premium 入口** | 首页标题栏右上角的“Premium”标签，点击打开 Premium 方案页；会员时变为带皇冠的实心金色“Premium”或“Premium+” | `.chip.premium`（会员加 `.on`）、`data-act="premium"` |
| **返回箭头** | 选项页标题栏左侧的“‹” | `.back` |
| **图标栏** | 面板最右侧一列竖排的图标按钮 | `#rail` / `.rail` |
| **悬停提示** | 鼠标移到图标栏按钮上弹出的黑色小标签 | `.rb[data-tip]::after` |
| **页面提示** | 面板底部短暂出现的提示，如“已删除” | `#toast` |

### 1.2 图标栏按钮（从上到下）

| 名称 | 作用 | 代码位置 |
| --- | --- | --- |
| **关闭按钮** | 收起面板 | `data-act="close"` |
| **首页按钮** | 切到首页；当前所在页高亮为金色 | `data-go="home"` |
| **设置按钮** | 切到设置页 | `data-go="settings"` |
| **翻译按钮** | 翻译 / 还原当前网页，翻译中图标为金色 | `data-act="togglePage"` |
| **划词按钮** | 打开“划词翻译”选项页 | `data-pick="selection"` |
| **字幕按钮** | 打开“双语字幕”选项页 | `data-pick="youtube"` |
| **生词本按钮** | 打开生词本；有生词时显示紫色**数字角标** | `data-go="words"`、`.badge` |
| **完整设置按钮** | 图标栏最下方，打开完整设置页 | `data-act="options"` |

### 1.3 首页

| 名称 | 指的是 | 代码位置 |
| --- | --- | --- |
| **生词本卡片** | 左上卡片：粉色爱心、生词数量 | `.stat[data-go="words"]` |
| **翻译引擎卡片** | 右上卡片：当前引擎名称，点击进入引擎选项页 | `.stat[data-pick="engine"]` |
| **翻译开关卡片** | “翻译此页面”、模式与语言说明、开关 | `.hero` |
| **网站卡片** | “总在此网站开启”开关、当前网址、“永不翻译 · N ›” | `.hero` 下方的 `.card.box` |
| **不支持提示** | 浏览器内置页面上，代替翻译开关卡片和网站卡片的灰色说明 | `.warn` |
| **本页生词区** | 当前网页上出现的生词列表 | `.words-card` |
| **区块标题** | 本页生词区顶部“本页生词 4”和右侧“展开释义 ⌄” | `.wl-head`；数字为 `.num`，按钮为 `data-act="expand"` |
| **生词行** | 列表中的一行：单词、展开时的译文、三个按钮 | `.word` |
| **掌握按钮 / 红心按钮 / 朗读按钮** | 生词行右侧的三个按钮 | `data-act="master"` / `"unsave"` / `"speak"` |
| **空状态** | 没有内容时显示的灰色图标和说明文字 | `.empty` |
| **快速翻译框** | 首页最下方的输入框及下方译文 | `#quickInput`、`#quickOut` |
| **开关** | 圆形滑块开关，开启时为紫色 | `input.sw` |

### 1.4 设置页与选项页

| 名称 | 指的是 | 代码位置 |
| --- | --- | --- |
| **设置页** | 图标栏“设置”进入的分组列表 | `VIEWS.settings` |
| **分组标题** | 灰色小字“主功能设置”“通用设置” | `.gtitle` |
| **设置行** | 每一行：图标、名称、当前值、“›” | `.ri`；当前值为 `.val` |
| **选项页** | 点击设置行后进入的单选列表 | `VIEWS.pick`，选项定义在 `PICKERS` |
| **选项** | 选项页中的一项，当前选中项右侧有紫色勾 | `.opt`、`.ck` |
| **选项说明** | 选项页底部的灰色小字 | `.hint` |
| **生词本页** | 生词本按钮进入的完整列表，顶部显示“已掌握 N / 总数” | `VIEWS.words` |
| **账户行** | 设置页第一行“账户”，显示邮箱或“登录 / 注册”，会员带金色“Premium / Premium+”标签 | `[data-go="account"]`、`.tag.pro` |
| **账户页** | 账户行进入的页面：未登录时为登录表单，登录后为会员信息 | `VIEWS.account` |
| **登录页 / 注册页** | 未登录时的账户页：大标题“欢迎回来”/“注册账号” | `VIEWS.account`，`.auth-title`、`.auth-sub` |
| **Google 按钮** | “继续使用 Google” | `.oauth`、`data-act="oauth"` |
| **图标输入框** | 左侧邮件 / 锁图标、竖线分隔、右侧输入框 | `.ifield`、`.iicon` |
| **金色主按钮** | “使用邮箱登录”/“使用邮箱注册” | `.gold.submit` |
| **游客按钮** | 注册页的“以游客身份使用”，返回首页 | `.outline`、`data-act="guest"` |
| **切换链接** | 登录页“注册账号”、注册页“已有账号，立即登录”（金色） | `data-act="authMode"` |
| **条款说明** | 注册页底部“注册即表示你同意《服务条款》……” | `.terms`，链接在 `config.js` 的 `TERMS` 中配置 |
| **表单提示** | 表单内红色（错误）或绿色（成功）的提示条 | `.msg.err` / `.msg.ok` |
| **会员卡片** | 登录后顶部的头像、邮箱、等级（免费版 / Premium 会员 / Premium+ 会员）、刷新按钮 | `.acct`、`.plan`、`data-act="acctRefresh"` |
| **状态说明** | 会员卡片下方的灰色文字，如“下次续费：……”“已取消续费……” | `.status-line` |
| **开通会员卡片** | 免费版的金色边框卡片，简介两档权益，按钮“查看会员方案” | `.pro-card`、`data-act="premium"` |
| **用量卡片** | Premium+ 会员的“本月 AI 用量”与进度条 | `.usage`、`.bar` |
| **升级按钮** | Premium 会员的“升级到 Premium+ 解锁全部 AI 引擎”，打开方案页 | `.gold[data-act="premium"]` |
| **管理订阅按钮** | 会员打开 Stripe 客户门户的按钮 | `data-act="portal"` |
| **等级标签** | 引擎选项页、设置页引擎卡片右侧的“免费 / Premium / Premium+”；未解锁时为灰色 | `.tag.free` / `.tag.pro` / `.tag.need` |
| **生词上限提示** | 生词本页顶部：免费版“最多 100 个 · 开通 Premium”，会员“已同步到账号” | 生词本页 `.hint` |

设置页各行的名称：账户、翻译引擎、双语字幕、沉浸翻译、译文样式、划词翻译、悬停翻译、输入框翻译、浮动按钮、翻译语言、网页语言、网站规则、配置快捷键、完整设置、关于（显示版本号与提交编号）。

### 1.5 Premium 方案页

独立的扩展页面 `premium/premium.html`，参考 Trancy 定价页的深色风格。

| 名称 | 指的是 | 代码位置 |
| --- | --- | --- |
| **方案页** | 整个会员方案页面 | `premium/` |
| **登录状态** | 右上角的邮箱和当前等级，未登录时为“登录”按钮 | `#who` |
| **周期切换** | 标题下方的“月付方案 / 年付方案”，年付带红色“省 N%” | `#period`、`data-interval` |
| **方案卡片** | 三张卡片：免费、Premium、Premium+ 高级 AI；当前方案金色描边并标“当前方案” | `.plan.free` / `.plan.premium` / `.plan.premium_plus`，当前加 `.current` |
| **开通按钮** | 卡片中的“开通 Premium”“开通 Premium+”；Premium 会员看到“升级到 Premium+”；当前方案为“当前方案 · 管理订阅” | `data-act="buy" data-plan`、`data-act="portal"` |
| **功能对比表** | “详细功能”表格，按基础功能、翻译引擎分组 | `#compare` |
| **常见问题** | 底部可展开的问答 | `.faq details` |
| **登录弹窗** | 未登录点开通时弹出，内嵌面板的登录页，登录后继续所选方案 | `#loginModal` |
| **支付成功弹窗** | 付款完成、回到方案页时弹出：“支付成功”、当前会员等级、已解锁的功能、“开始使用” | `#doneModal` |
| **结果提示条** | 方案页顶部的提示，如“已取消支付”“订阅已更新” | `#notice` |

## 六、完整设置页

从图标栏“完整设置按钮”打开的独立网页。

| 名称 | 指的是 | 代码位置 |
| --- | --- | --- |
| **侧边导航** | 设置页左侧的分区列表 | `options.html` 的 `nav` |
| **分区** | 基本设置、翻译服务、AI 翻译设置、译文样式、划词与悬停、视频字幕、网站规则、高级 | `section.sec`，锚点如 `#engines` |

| **后端切换** | “高级”分区的“后端（开发版）”下拉框：云端 / 本地；只在开发版显示，切换会退出登录 | `#devBackendRow`、`#devBackendSel` |
| **刷新提示条** | 磁盘代码已更新、插件还没刷新时，设置页顶部与面板首页的黄色提示 | `#staleBar`、`.stale-bar` |

插件代码已更新，但 Chrome 里运行的还是旧版本。请到扩展管理页点击微光翻译的“刷新”按钮。

基本设置

选择你的母语和偏好的翻译方式，网页会以双语对照的形式呈现。

翻译服务

Google 翻译免费使用；DeepL、Microsoft 需要 Premium 会员，GPT、Gemini、DeepSeek、Claude 需要 Premium+ 会员。付费引擎均由微光翻译服务器提供，无需也不能填写 API Key。查看会员方案

译文样式

为双语模式下的译文选择一种样式。“学习模式”会模糊译文，鼠标悬停才显示，适合练习阅读。

The best way to learn a language is to immerse yourself in it every day.

学习一门语言最好的方法，是每天沉浸其中。

划词与悬停

选中文字即可翻译；按住修饰键并把鼠标悬停在段落上，可单独翻译这一段。

视频字幕

在 YouTube 打开字幕（CC）后，自动显示双语字幕。鼠标移到字幕上会暂停视频，点击单词可查看释义。

网站规则

每行一个域名，子域名会自动匹配，例如 medium.com。
